# Animal-specific Lion access review

Decision: **obtain one authorized source archive before another construction experiment**. Prefer LazyGraph's editable big-cat base for a topology/rig inspection; keep doizy as the first alternate for its low reported scene cost. None of these three is adopted or accepted as finished art. No model geometry was downloaded, no Blender process ran, and no account, purchase, terms acceptance or private upload was attempted.

## Exact access boundaries

The two Sketchfab public metadata requests returned HTTP 200 and are retained verbatim. Their documented `/v3/models/{uid}/download` requests, made without any credentials, returned **HTTP 401** with an authentication-required response. The [official download documentation](https://sketchfab.com/developers/download-api/downloading-models) confirms that a Sketchfab account is required before obtaining temporary archive links. Public listing and `isDownloadable` metadata do not mean anonymous geometry access. No viewer mesh extraction, protected URL scraping or alternate mirror was attempted.

LazyGraph's [download page](https://blendswap.com/blend/27158/download) exposes a Blender 2.9x file entry and the instruction “Sign in to download.” Its link leads to [BlendSwap sign-in](https://blendswap.com/login), offering account sign-in; no login was performed. Web retrieval obtained these pages, while a separate unauthenticated raw HTTP fetch returned 403. Both facts are recorded; the 403 response is not mislabeled as captured page HTML. The direct anonymous file URL is therefore unknown, and no guessed storage URL was tried.

Sketchfab model-page web retrieval initially returned 403 while public API metadata succeeded. Primary indexed publisher results independently identify the two listings and licenses. Preview image retrieval did not yield reviewable images in this leaf; no image was downloaded to work around that limitation. Thus this is an access/provenance comparison, not a new visual-art verdict.

## Smallest owner action and next bounded work

Recommended one-file handoff: the owner opens [LazyGraph's download page](https://blendswap.com/blend/27158/download), signs in personally, downloads the free Blender package, and supplies its local path. No credentials or API token need to be shared. This is the most direct advertised editable animal-body/IK source among the three; choosing it first is an inference from the publisher's format and rig description, not an adoption decision.

If using an existing Sketchfab account is easier, the alternate is [doizy's Lion](https://sketchfab.com/3d-models/lion-79d5e1173bba4f2b80661620a2eca9bc): use its Download 3D Model route and retain the original-format archive if offered, plus the converted glTF archive when available. Do not assume the original is a `.blend` file. Zee remains third until its animation-organization discrepancy and source format can be checked.

After that single authorized archive is available, the next experiment is source inspection with auto-execution disabled: measure actual connected quadruped anatomy, paws/hocks, spine/scapula/pelvis layout, topology/UVs, weights, materials/texture memory, bones and every supplied action; then inspect matched unflattering views and a bounded deformation probe. Only those results can decide whether the animal base supports a coordinated upright form, contact envelope and target style. No new procedural creature, full retarget, two-form rebuild or runtime promotion is authorized by this access review.

## Durable evidence and limits

`primary/doizy-metadata.json` and `primary/zee-metadata.json` contain the public publisher metadata. `primary/*-download-boundary.json` contain the actual 401 responses. `primary/sketchfab-download-docs.html` is the successfully fetched official documentation. `primary/lazygraph-*.html` are explicitly retained 403 diagnostics, **not successful page captures**. `PRIMARY-NOTES.md` records concise paraphrases of the primary pages successfully read through web retrieval, their URLs and access paths. `requests.json` records status, type, size, final URL and SHA-256 for each direct request; `manifest.json` binds the evidence and verifies the canonical asset freeze.

The three manual gates close the bounded sourcing/access decision only. Actual geometry, downloaded package formats where unknown, source rig quality, quadruped-to-upright construction cost, full motion, phone performance and cinematic A2 remain open.
