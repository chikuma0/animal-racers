# Production decisions

2026-09-16 — Written commission selects cinematic stylized 3D spaghetti-western: frontier/canyon race, timber saloon fight, gold handled cup. Earlier jungle direction superseded. Referenced PNGs and supplementary QA package not present in searched folders. No alternate art choice is being requested.

2026-09-16 — First architecture experiment: browser WebGL2 with Three.js + Blender GLB. Existing Next/Vercel distribution and public invite links make two-device access practical. Pure deterministic fixed-step simulation separates rendering/input/network. Unity/Godot/Unreal not installed; native distribution/signing would add an unproven gate. This is a provisional experiment, not a claim of iPhone60fps. Measure representative assets, camera, lighting, touch and two clients before locking.

2026-09-16 — Casual friend match with host authority. Guest transmits validated input, never damage, positions or scores. Host computes both players and all transitions, hits, finishes and championship. Guest interpolates positions and animation between bounded authoritative snapshots without predicting hits or advancing canonical state; expose weak connection and stop on peer loss. The host is trusted; no ranked/anti-cheat claim. Shared Supabase transport must be timed; no schema or shared settings changes.

2026-09-16 — Independent race/fight performance, equal capped point pools, no race-derived combat buffs. Same max HP and physics for humans and CPU. Score only terminal outcomes; no healing/attack-count farm. Ties can award a shared championship instead of arbitrary id/order tiebreak. Forfeit/disconnect clearly labelled rather than masquerading as a played win.

2026-09-16 — User authorizes downloading necessary free tools and will make physical iPhone/second player available when test build is ready. No purchase, new paid subscription or private upload to a new asset service authorized.

2026-09-16 — Three unsuccessful upright deformation repair cycles triggered a topology reassessment. A dedicated connected Unicorn upright mesh removed the largest shoulder sheets and torso collapse in paired views while retaining fixed limb lengths. Extend this coordinated-mesh approach to all three animals; retain the original quadruped racing meshes and shared face/species elements. Transition uses the saloon scene cut and an authored crouch-to-stand arrival. It is not a continuous cross-topology morph. The extra three GLBs add startup/memory cost that remains subject to physical-phone measurement. Geometry feasibility is passed for the experiment; cinematic acceptance remains open.
